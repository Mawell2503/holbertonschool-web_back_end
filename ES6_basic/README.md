# JavaScript
In JS variables are declared using let & const
**const** stands for constant;" keep this variable constant throughout the code"
**let** stands for "let this variable change"
**var** an old way to declare variables that isnt used today but is pratical.
compared to **let** and **const**, **var** can work in and outside function block.


__this__ & __new__ 
__this__ is utilise inside functions when you want the function to behave like a class.
it initiates variables, objects and instances that makes a function act and behave like a class.
__new__ is what turns the gibberish that this created into a proper class.
