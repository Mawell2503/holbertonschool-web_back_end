# JavaScript(JS)
## JS Variables types

**const** stands for constant;" keep this variable constant throughout the code"
**let** stands for "let this variable change"
**var** an old way to declare variables that isnt used today but is pratical.
> compared to **let** and **const**, **var** can work in and outside function block.

## JS Function's Keywords

__...__ (spread syntax/rest parameter) is a powerful tool in javascript.
>> It acts like a net. It gathers up all individual arguments passed into the function and "envelops" them together into a single, neat array
>> When used inside a function header it takes seperate elements and combines them together into an array
>> When used inside a funnction body it explodes/open an array and seperate its elements


__this__
>> utilised inside functions when you want the function to behave like a class.
>> initiates variables, objects and instances that makes a function act and behave like a class.

__new__
>> is what turns the gibberish that this created into a proper class.
